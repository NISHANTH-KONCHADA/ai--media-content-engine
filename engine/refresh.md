# A cleaner recording handoff

An original second workshop, used to demonstrate refresh. Proposed practices, not measured customer outcomes.

## Record a useful room-tone sample
Capture a short sample of the room before the conversation. Keep it with the recording so the editor can hear the background conditions.
Listen through headphones before starting. Move away from fans or rattling objects when practical. A quiet location is easier to work with than a noisy file.
Try this: play back the first test sentence before recording the whole interview. Correct the problem while the speaker is still available.

## Ask permission before reuse
Explain where an interview excerpt might appear before recording. Capture the participant's permission in the project record.
Permission for one use may not cover another. Check the agreed scope before turning a private session into a public clip.
Try this: include a reuse checkpoint in the editor handoff. Leave content unpublished when permission is unclear.

## Leave a searchable handoff note
Give the editor a clear filename and the recording date. Include the topic and the speaker's approved display name.
Record technical problems while you remember them. Mark a false start or a corrected fact so it does not become the selected clip.
Try this: search for one source file using only the handoff note. Improve the note if you need to ask the recorder for help.

## Review the export before scheduling
Watch the complete exported file on a phone. Look for unreadable text, cropped faces and accidental private information.
Compare the caption with the final video. If a key point changed during editing, the caption should change too.
Try this: open the actual scheduled media file, not the editor preview. Review what the audience will receive.
